# HUST 演示子集

此目录的 4 个 NPZ 文件来自用户已有的 PFLlib HUST 数据分片，包含三客户端的 288 条训练信号，以及另取自原测试分片的 80 条测试信号。文件总量约 2.9 MiB。

类别：0 正常、1 内圈故障、2 外圈故障、3 滚动体故障。Y 通道、每条 2048 点、逐窗口零均值/单位标准差。`samples.json` 仅用于页面展示抽样波形和真实标签，预测不读取其标签。

上游预处理记录为按 source chunk 分配、划分后窗口化；本次保留上游 train/test 边界，并排除训练样本与测试样本完全相同的窗口。`manifest.json` 列出源分片索引与校验值，可用 `scripts/prepare_data.py` 复现。

此子集用于用户的算法演示。代码的 Apache-2.0 许可不自动覆盖上游原始数据的授权；原始 HUST 数据权益归其原权利人。本仓库没有新增或替代原始数据许可。
